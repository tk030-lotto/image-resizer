# エージェント行動規範（AGENTS.md）

このファイルはAntigravity IDEが会話開始時に自動ロードする強制ルールです。

## 【最重要】ルール正本の参照先

すべての開発ルール・行動規範は **プロジェクトルートの AI_RULES.md** に一元管理されています。
作業開始前に必ず AI_RULES.md を読み込み、記載されたすべての指示に従ってください。

---

## Antigravity IDE 専用設定

### AIコンテキスト管理MCPツールの積極利用義務
AIアシスタントが開発・分析・ファイル走査・コード生成を行う際は、自発的に **「AIコンテキスト管理MCPツール」** を優先的に呼び出し、トークン消費量を最小化しながら作業を進めること。

### 新規プロジェクト開発開始時の標準手順
1. **ルール一括同期の実行**: `C:\Users\tk030\Desktop\各種情報\sync_rules.ps1` を実行し、ルールファイル一式を配置・同期すること。
2. **GitHubプライベートリポジトリの初期作成**: `gh repo create <repo-name> --private --source=. --remote=origin --push` を実行すること。
3. **ライセンスの明記**: `README.md` に MIT ライセンス全文を記載し、`LICENSE` ファイルを配置すること。

### カスタムエージェント自律委任パイプライン規約
AIアシスタントは .agents/agents/ または ~/.gemini/config/agents/ に配備されたカスタムエージェントをタスクの性質に応じて自律的に呼び出すこと。

- **planner**: 新機能・大規模改修時の要件整理と段階的計画。
- **ug-fixer**: エラー・テスト不合格時の自律修正。
- **eviewer**: コード修正完了時の客観的品質監査（ファイル変更不可）。
- **doc-writer**: 仕様・README・マニュアルの技術文書作成。
- **context-archivist**: 作業完了時の `RECORD.md` 更新・永続化。

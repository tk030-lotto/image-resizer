# 画像一括リサイズツール（Image Resizer）
複数の画像の長辺（px）をそろえて、まとめて縮小するブラウザツールです。

## こんなときに
- ブログ、SNS、フリマに出す写真を、同じサイズにそろえたいとき
- メールや資料に貼る画像のファイルサイズを、まとめて小さくしたいとき
- 1枚ずつ画像ソフトで開き直して縮小する手間を減らしたいとき

## 主な機能
- **まとめて縮小**: 複数の画像をドラッグ＆ドロップ、またはファイル選択で一度に処理します。
- **長辺（px）指定**: 縦長・横長・正方形を判別し、長い方の辺を指定したピクセル数に合わせて縦横比を保ったまま縮小します。
- **小さい画像はそのまま**: 元の画像の長辺が指定サイズ以下のときは、引き伸ばさずに元のサイズで出力します。
- **スマホ写真の向きを反映**: 写真に記録された回転情報（EXIF Orientation）を読み取ってから縦横を計算します。
- **元画像の保護と同名回避**: 元のファイルは書き換えず、同じ名前のファイルがあるときは `image_001.jpg` のように連番を付けて保存します。
- **対応形式**: JPG / JPEG / PNG / WebP に対応しています。

## 使い方

### ブラウザで使う（かんたん）
1. [ツールを開く](https://zero-dev.jp/image-resizer/) をクリックします。
2. 「画像を選択する」（または右上の「画像を選択」）を押して画像を選ぶか、画面に画像をドラッグして置きます。
3. 画面に「選択中のファイル」の一覧が表示されます。取り消したい画像があるときは、行の右端の削除ボタンか「すべてクリア」を押します。
4. 必要なら、「長辺サイズ」の欄にピクセル数を入力するか、「1920 (FHD)」「1280 (HD)」「1080 (SNS)」「800 (Web)」のボタンを押して選びます（初期値は `1280` です）。
5. 必要なら、「保存フォルダ名」の欄に出力先のフォルダ名を入力します（初期値は `resized` です）。
6. 「変換開始」を押します。
7. Chrome や Edge では、保存先フォルダを選ぶ画面が出るのでフォルダを選ぶと、その中にサブフォルダ（`resized` など）が作られて保存されます。その他のブラウザでは、`resized.zip` としてまとめてダウンロードされます。
8. 画面の下に「変換完了」と、成功・失敗の件数、保存先の一覧が表示されます。

### ダウンロードして使う（パソコンに保存する場合）
1. 本リポジトリをダウンロード（ZIP）またはクローンして展開します。
2. フォルダ内の `index.html`（Windows 環境では `ツール起動.bat`）をダブルクリックしてブラウザで開きます。

## うまくいかないとき
- **ファイルが「非対応」と表示されるとき**: 対応している形式は JPG、JPEG、PNG、WebP の4種類です。GIF、BMP、HEIC などのファイルは、あらかじめ対応形式に変換してから追加してください。
- **変換しても画像の大きさ（ピクセル数）が変わらないとき**: 元の画像の長辺が、指定した「長辺サイズ」よりも小さい場合は、画質の低下を避けるため拡大せずに元のサイズで出力します。
- **保存先フォルダへの書き込みエラーが出るとき**: 選んだフォルダへのアクセス許可が拒否されたか、OS で保護されたフォルダ（システムフォルダなど）を選んでいる可能性があります。デスクトップやピクチャなどの通常のフォルダを選び直してください。

## 動作環境
- モダンブラウザ（Google Chrome、Microsoft Edge、Firefox、Safari の最新版）
- フォルダへの直接保存（File System Access API）は PC 版の Chrome / Edge に対応しています。Firefox、Safari、スマートフォンでは ZIP ファイルでの一括ダウンロードになります。

## 制限・注意
- 対応形式は JPG / JPEG / PNG / WebP です（WebP の保存に対応していないブラウザでは、WebP 画像は PNG 形式に変換して保存されます）。
- 長辺サイズの指定範囲は `1`〜`20000` px（整数）です。
- JPEG と WebP の書き出し品質は `0.92`（92%）固定です。Canvas で再エンコードするため、元の画像にあった撮影日時や位置情報などのメタデータ（EXIF）は出力画像には引き継がれません。
- すべての処理をブラウザのメモリ上で行うため、高解像度の画像を一度に数百枚まとめて変換すると、端末のメモリ不足で動作が重くなったり失敗したりすることがあります。枚数が多い場合は数十枚ずつに分けて実行してください。

## 外部通信
通信しません。選択した画像データや設定はすべてお使いの端末（ブラウザ）内で処理され、外部のサーバーへ送信されません。
